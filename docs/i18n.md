# Translations: what is translated, and how

Languages: zh-CN, ja, ko, es, pt-BR, de, fr. English is the default and has no prefix.

The translations were written by AI and have not been reviewed by native speakers.

## What is translated

| Part | Address | Where the words are |
|---|---|---|
| Home | `/<locale>` | `messages/<locale>.json`, `Home` |
| Online face swap overview | `/<locale>/face-swap` | `messages/<locale>.json`, `FaceSwap`, `OnlineTools` |
| Video FaceSwap page | `/<locale>/facestudio-v` | `messages/pages/<locale>.json`, `video` (Chinese: `app/[locale]/facestudio-v/zh-page.tsx`) |
| Nano FaceStudio Online page | `/<locale>/face-studio` | `messages/pages/<locale>.json`, `faceStudio` |
| Nano ImageEdit page | `/<locale>/image-edit` | `messages/pages/<locale>.json`, `imageEdit` |
| Nano HeadSwap Pro page | `/<locale>/headswap-pro` | `app/headswap-pro/copy.ts` (en, zh-CN, ja), `messages/pages/<locale>.json`, `headswap` (the rest) |
| Navbar, footer, sign-in, sign-up, credits | same address in every language | `messages/<locale>.json`, `Ui` |
| Face Studio, ImageEdit and HeadSwap tool screens | same address in every language | `public/i18n/tools-<locale>.json` |

`messages/pages/en.source.json` is the English the translators worked from. It is not shown on the site. When the facts in it change, change the translations too.

## Left in English on purpose

- Price lists, refund terms and legal text: `/pricing`, `/terms`, `/privacy`, the footer disclaimer, the auto top-up terms and consent, "1 credit = $0.01", and the "Packs start at $5" lines. Translated pages link to them and say they are in English.
- The prompts sent to the image model: presets, the example chips and the field placeholders. The translated ImageEdit page tells people to write instructions in English.
- Forgot-password and reset-password pages, the account page, desktop licence checkout, desktop app pages, the blog (except the Chinese guides), and the emails Supabase sends.

## Not in this repository

The video studio's screens (the address in `FACESTUDIO_V_STUDIO_URL`) are served from the GPU machine, so they are still in English. `OnlineTools.englishNote` and the video page FAQ say so. Update them when it is translated. Copying `public/i18n/tools.js` and a dictionary there is one way to do it.

## How a language is chosen

- Pages with a prefix use the prefix.
- `/auth/*` and `/credits` use `negotiateLocale` in `middleware.ts`: the `np_locale` cookie, else the browser's `Accept-Language`, else English.
- Tool screens do the same in the browser (`public/i18n/tools.js`). Change the two together.
- `app/components/locale-switcher.tsx` sets the cookie, when someone picks a language and when they browse a page with a prefix. Middleware must not set it: cached pages cannot send cookies.

## Tool screens

`public/i18n/tools.js` replaces a text node or attribute only when its whole text is a key in the dictionary. Anything else stays in English, so a new string fails safe. Keys with `{n}` match numbers. Many keys are pieces of one sentence split by a link or bold word, so a change to the HTML can leave a piece unmatched.

## Adding a page

1. Add its copy to `messages/pages/en.source.json` and to each language.
2. Add the path to `TRANSLATED_PAGES` in `lib/i18n/locales.ts`. The switcher, nav and footer use this list.
3. Add it to `app/sitemap.ts` with `translatedEntries`, and give the English page `alternates.languages`.
